# AutoMind AI

Intelligent Service Management for the Automotive Industry — a production-style B2B SaaS frontend built with Next.js, React, and Tailwind CSS.

## Features

- **Marketing Website** — Hero, features, analytics preview, AI insights, pricing CTA, and footer
- **SaaS Dashboard** — Collapsible sidebar, top bar with search, notifications, branch selector, and profile
- **Application Screens** — Appointments, Customers, Vehicles, Job Cards, Spare Parts, Branches, Analytics, AI Insights, Reports, Settings
- **Mock Data** — Realistic static data ready for future FastAPI + PostgreSQL integration
- **Charts** — Recharts-powered dashboards for service volume, revenue, trends, and more

## Tech Stack

- Next.js 15 (App Router)
- React 19
- TypeScript
- Tailwind CSS 4
- Recharts
- Lucide React icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) for the marketing site.

- **Dashboard:** [http://localhost:3000/dashboard](http://localhost:3000/dashboard)
- **Login:** [http://localhost:3000/login](http://localhost:3000/login)
